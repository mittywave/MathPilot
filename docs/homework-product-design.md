# 作业系统产品与交互原则

## 产品目标

作业批改是工具箱里的独立工具（`/tools/homework`），不属于学生档案。平台不用于布置作业，也没有学生端；老师上传学生已完成的作业，系统自动完成可以可靠完成的工作，看不清或无法核实的题目单独待处理，不把拍摄问题算成学习问题。

批改本身只产出这份作业的批改记录。写入学生的内容是三个独立模块，上传时按作业逐项选择，由 `lib/server/homework-outputs.ts` 统一调度：

| 选项 | 模块 | 默认 |
| --- | --- | --- |
| 加入学生错题本 | `homework-wrong-book.ts` | 开 |
| 生成错题报告 | `homework-reports.ts` | 开 |
| 整合到学生画像（知识图谱） | `homework-capabilities.ts` | 关 |

选项保存在作业上（`homework_assignments.outputs_json`），同一作业的新版本沿用；发布、教师修正、补全配图后，只重新运行已选的模块。三个模块目前是框架，各自的规则后续单独开发。

## 界面原则

- 一个页面、一个状态、一个主要操作。
- 先结论、后证据；先当前任务、后历史信息。
- 能省的按钮就省，低频操作收进折叠区、弹层或更多菜单。
- 按钮横排、文案简短，不用竖排文字，不依赖图标猜含义。
- 上传保持“选择照片或 PDF—提交—查看结果”的单一路径；照片按原样批改，不做纸张检测或透视校准。
- 掌握情况只用于帮助理解，不展示伪精确分数；必须同时提供清晰的文字结论。

## 性能与无障碍

- 主要操作最小触控高度为 40px，桌面和 390px 移动端均不得产生页面级横向滚动。

## 中国课程知识图谱

知识图谱采用“课程节点—教材定位—题库题目—学生证据”的单一数据链路：

1. `cn-math-junior-v1` 提供稳定知识节点、父级领域、年级阶段和有向前置关系。
2. 人教版、北师大版和苏教版映射到同一知识节点；教材版本只是定位层，不复制三套知识图谱。
3. 题库题目和作业题目保存稳定 `taxonomyKeys`，AI 生成的自由知识标签仅用于辅助映射和人工校正。
4. 批改结果通过题目节点生成学生证据；无法辨认的拍摄问题不进入知识图谱。
5. 教师端展示完整前置路径、题号证据、关系依据和教材定位。

数据与可视化运行时分离：`data/china-math-taxonomy.v1.json` 是图谱 v1 种子，之后的版本由教师在 `/knowledge-graph` 编辑并发布到 D1（见 `docs/knowledge-graph-design.md`）。校验器检查稳定 ID、引用完整性和 DAG 无环；Canvas 只按年级和课程领域投影节点，不把业务分类写死在绘图代码中。

V1 当前是七至九年级数学课程骨架。三个教材版本已建立框架级映射，但具体册次与章节仍标注为“待校准”；未经过教材目录核对前，不得将其展示或宣传为精确章节定位。

## 已完成作业直接批改

老师在学生档案或作业记录中选择“上传作业并批改”，选择学生并上传已完成作业。支持图片和 PDF，参考答案可选。原件保留，作业题干识别、独立参考解答、参考解答校验和学生作答判断分开处理。仅完全错误归入当前错题本；部分正确只保留在作业记录，待补图或待核实不产生错题及负面学习证据。

校内作业每页练习各自编号，题目以“起始页码-印刷题号”标识，显示为“第 5 面 第 3 题”；有小问的题每个小问单独成题（5-3(1) 显示为“第 5 面 第 3 题 (1)”），题干带上大题的公共条件，各自判定、各自进入错题本。老师已经批改过的题按作答旁的批改符号判定：对勾为正确，半对勾为部分正确，叉或圈出答案为错误；这些题不求解、不比对、不写解析，判错即进入错题本，不需要参考答案。没有批改符号的题由 AI 解题并判对错，只保留结论和参考答案的最终结果，不写解析、步骤分析和反馈。

原卷印刷了分值（如“(5 marks)”“（5分）”）时按步骤给分：方法分与答案分分开，接受等价表达和有效替代解法，同一错误不重复扣分。满分随题目识别保存，老师可补填或修正满分与得分，得分决定结论（满分为正确、0 分为错误、其余为部分正确）。总分的分母始终是整份作业；仍有待处理题时只显示已确认得分和待定题数，不显示得分率。没有印刷分值的作业不显示分数。写失分反馈时（IGCSE / A Level），写清哪一步失分、涉及的知识点或步骤和订正动作；报告建议附可观察的完成标准，措辞只描述本次作答，不归因粗心或态度，不推断用时与考试等级。

### IGCSE / A Level 批改

上传时选择课程：“校内数学”沿用上面的流程；“IGCSE / A Level”按 Alevel 项目已确认的批改规范处理。公立小学、公立初中的专门规则暂未制定，目前都走“校内数学”。

- 按印刷分值的粒度拆题：单独印了分值的小问各成一题（如 3(b)(ii)），分值只印在整题末尾时整题为一题。题干保留英文原文，并带上本大题的公共条件和配图条件。每次上传一份试卷，题号保持印刷题号；同一题号在两页都被识别为起始页时，说明有页面识别错误，系统丢弃这些页的识别结果并重新识别。
- 参考解答写成本小问的评分要点（方法分 M、结果分 A、独立分 B，FT、AG 说明），分值合计须等于印刷分值。有 mark scheme 时按其得分点转录，没有时按考试局惯例拟定，核验时同时检查分值合计。
- 逐个得分点给分：结果分只在对应方法分已得时给，沿用自己前面的错误结果时按 FT 继续给分，show that 题须完整推导，未指定时按 3 位有效数字、角度 1 位小数判精度，接受等价形式和有效替代解法。逐点结论（如“M1 ✓”）留给老师核对；给学生和家长的反馈用中文，不出现评分代码。
- 空白和看不清的作答记 0 分，计入满分；看不清的小问仍列为待处理，补交清晰照片后可重批。缺页、题意不完整或参考解答未通过核验的小问不计分，得分率待全部定分后给出。
- 批改报告由家长和学生共读，结构沿用 Alevel 已确认的版式：成绩概览、本次学习表现（引用题号，优先改进 2—3 项）、按大题汇总的分题成绩、逐项失分分析（失分事实、知识与能力、正确思路、订正动作，覆盖每一处失分）、按优先级的练习建议及完成标准。看不清记 0 分的小问只说明评分事实和补做动作。报告页的主要操作是“下载报告 PDF”，由本机 Tectonic 排版；不能排版的设备可下载自包含的 TeX 源文件。

题干只保留原卷印刷的文字，“如图”保持原样，不用文字补写图形内容。每页识别时，模型同时给出本页每道题的印刷配图位置；选项本身是图形时，全部选项图连同字母作为一幅配图。系统从作业页面上按完整笔画裁出配图，框边相邻的文字被抹去，阴影和偏色纸面也被压白。配图随题显示在错题本和逐题批改记录里，宽图放在题干下方。图中解题所需的条件另存为“配图说明”，只供解题、核验和批改参考，不在错题中展示。图上学生或老师的笔迹仍随原图保留。配图功能上线前识别的作业，可以在批改记录页一键“提取题目配图”：系统逐页定位配图，并移除当时写进题干的图形说明。只删除模型原样引用、与题干逐字吻合的部分，或者两端吻合、整体差异不超过一成的部分。

待处理题可以补图或由老师补充题干、参考解答并确认判定。重处理只更新待处理题；补图前原件单独保留。每个批改项是一条错误发生记录，重试和重复发布不累计次数，同题的新提交版本可以累计。教师修正后按有效错误发生记录重新计算，历史手动记录和被撤销的记录保留在历史区。只有选择“整合到学生画像”的作业才写入图谱能力证据；批改结果页不加载学习图谱。

## 多页作业完整性门槛

直接上传的作业逐页识别，每次只处理一个主页面并使用相邻页判断续题，同时最多执行两次模型请求。每页必须返回本页回执、页面类型和可见题号清单；题号清单与本页题目正文必须一一匹配。空白与不可读页面必须明确说明，不能当作遗漏忽略。

成功回执按提交、页面及邻页图像指纹保存。重试恢复已成功页面，换图后相关回执失效。没有所有当前页面的有效回执时，不允许确认模板、发布结果或显示整份完成。解题、参考答案核验和批改每批最多6题，返回题号必须与请求题号完全一致，缺题或重复题号视为不完整输出并停止任务。不可核实的题目明确保留为待处理，不进入错题本。上游服务失败时队列自动重试，等待重试期间提交仍是“批改中”并显示重试说明，不允许手动重新批改，避免同一份作业同时跑两次、重复计费；用完重试次数才标记为处理失败。

历史提交缺少新回执时，结果页标记“已有结果不完整”，可以使用“补全页面并重新批改”恢复；修复前逐题批改保留在修正历史中。完整性回归覆盖“只返回开头页面”“错误页码”“题号清单与正文不匹配”“明确空白/不可读页”“跨页续题”“分批结果缺题”和“中断后按页恢复”。此门槛防止漏处理页面却发布完成；模型对单个字迹、公式或题意的判断仍需通过原卷证据与教师修正核实。
