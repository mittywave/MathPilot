# 题库编号与查找

所有题库模块共用编号，已有题目按创建时间补号，新题由数据库原子分配。编号从 `0001` 开始，至少四位；超过 `9999` 后自然扩展为五位，不截断或复用。

题卡与讲义选题器显示 ID。输入完整 ID 命中题目时跨模块、分类和题型精确查找；未命中则仍按现有范围搜索正文、答案、年份和知识点。

内部 UUID 继续用于讲义与图片关联。`question_codes` 按 UUID 保存独立的永久编号，因为题目表含发布版本且可被物理删除，不能直接用行号稳定编号。编辑、移动、删除恢复、同 UUID 的发布版本均保留编号；导入为新 UUID 的副本分配新编号。编号由服务端控制，不接受客户端指定。永久删除也保留编号映射，避免旧编号指向其他题。

编号唯一性范围为当前数据库内的所有题库；独立部署各自分配，不承诺跨服务器相同。作业批改中的临时题目和学生错题记录不属于题库记录。

## 讲义书架

讲义只有一种，按存放位置分在三个书架上，编辑器和导出都一样：

- **课程体系**：按年级、学期、课次编排，课次号就是讲义在本学期里的先后。全员共用。
- **专题库**：按函数、几何、代数、数论、数学思想五个板块存放知识专题，不分年级。全员共用。以前没有归入课次的讲义暂放在“未分板块”，移走后这一列就不再显示。
- **学生讲义**：挂在学生档案下，只有这位学生的老师能看到、编辑和删除；删除学生时，这位学生的讲义一起删除。

书架由讲义的存放字段推出，不另设类型：有学生的是学生讲义，有学期的是课程体系，其余都在专题库（按板块，没有板块的是未分板块）。共享讲义只有管理员能删除。

讲义书架页不再重复页面标题。左侧是书架导航，顶部可以按讲义标题或模块名查找全部书架；右侧用满整个宽度：课程体系并排列出所选年级的暑假、秋季、寒假、春季，专题库并排列出五个板块，学生讲义列出这位学生的全部讲义。每条讲义显示课次号（课程体系）、标题、各模块名（模块之间用“；”分隔，因为模块名本身常带“、”），右侧上下排着讲义、小测、作业各有几道题，没有题的变淡，一眼看出哪一讲还缺小测或作业；上移、下移、复制一份、移到…和删除收在“更多”里，鼠标经过或键盘聚焦时出现，触屏上一直显示。每一列末尾是“添加第N讲”“新建专题”或“为某某新建讲义”。“移到…”可以在课程体系（选年级和学期）、专题库（选板块）和自己的学生之间移动，移到学生名下后只有自己能看到。编辑页底栏的返回链接写明讲义所在位置，如“初二秋季”“几何专题”或学生姓名，并回到对应书架。

## 讲义内选题

打开一份讲义后，桌面端采用左侧题库、右侧讲义的双栏布局，两栏独立滚动。左侧题库最左边是与题库页相同的知识目录，点选模块或分类即按该分类及其子分类筛选；旁边的选题列表可切换模块和题型、按 ID 查找并批量选择；指定讲义知识模块与例题／练习／变式后加入，已在讲义中的题目不可重复加入。加入后保留筛选条件和目标位置，清空本批选择。编辑页不设顶栏：返回、保存状态和导出放在知识目录底部，讲义标题放在右侧讲义栏顶部，随讲义一起滚动；选题列表上方加入位置占一行，搜索、模块和题型在列表够宽时占一行、否则占两行，题目卡片配图限高，让一屏能浏览更多题目。选题列表与讲义栏宽度大致相当，讲义栏不再大片留白。

编辑页铺满整个窗口。右侧讲义按成品的样子排：标题下是各知识模块，模块序号和精排 PDF 一样做成圆角色块，上移、下移、删除模块收在模块标题行的“更多”里。每个模块依次是知识点、例题、练习、变式，每一段是一个圆角框：带底色的标题栏写段名，题数用圆形徽标（有题时实心，没有题时是空心灰圈），没有题的段只剩标题栏。编辑页不显示印在 PDF 和 Word 里的引导语，也没有空白提示框。知识点编辑框嵌在本段的框里，编辑时整段描边。每段标题栏右侧是“从题库选题”“录入新题”两个文字按钮，正在接收左侧选题的那一段整框描边。题目之间用细线分隔，题目下方一行写题型、所在分类和考点（没有考点时可直接补充），右侧是上移、下移、替换、更多和红色的“移出讲义”。

右侧各栏的“从题库选题”会定位左侧并切换加入位置；“替换”在左侧选一道题替换，保留原位置和用途，也可取消替换。题目卡片上直接显示红色“移出讲义”按钮，点一下即从讲义移除，题库原题不受影响；改为其他用途、编辑原题放在“更多”里。删除目标模块后，加入位置回退到第一个现存模块；无模块时需先添加知识模块。宽度不超过 1200px 时隐藏知识目录（仍可搜索分类名），返回、保存状态和导出移到题库顶部；不超过 900px 时上下排列，题库结果区仍独立滚动。讲义列表、知识点编辑、自动保存及导出规则不变。

## 一讲三份资料：讲义、小测、作业

每一讲（书架上的每一份讲义）有讲义、小测、作业三份资料，共用标题、书架位置和课次。编辑页标题右侧切换三份资料，每份旁边是题数徽标；地址记住打开的是哪一份（`?sheet=quiz`、`?sheet=homework`），刷新或打开链接回到同一份。

- **讲义**按知识模块编排，规则见上。
- **小测和作业**各是一列题，编号 1、2、3…，没有例题、练习、变式之分。每道题下方的“考查”选择它考的是本讲哪个知识模块。左侧题库的加入位置写成“加入小测，考查［模块］”，新加的题默认考查这个模块；“录入新题”录好的题加到当前这一份。上移、下移只在本份资料里换位置；“替换”保留位置和考查模块。
- 一道题在同一份资料里只出现一次；在本讲另外两份资料里用过的题，左侧标出“讲义已用”“小测已用”等，但仍可以选。
- 删除知识模块时，讲义里这个模块的题随模块一起移出；考查这个模块的小测、作业题保留，改为考查前一个模块（删的是第一个模块时改为后一个，一个模块都不剩时显示“未选模块”），删除前会提示。复制一份讲义时，小测、作业题考查副本里对应的模块。
- 从课程知识图谱的节点卡片点“打开讲义”时，地址带 `?module=`：编辑页滚到这个模块，左侧题库的加入位置也指向它。
- 导出的是当前打开的那一份。小测、作业的精排 PDF 标题区标签写“小测”“作业”，信息栏是姓名、班级、得分，只排题目、不印考点；答案的三种放法和讲义相同，学生版给解答题留作答空间。Word 标题为“讲义标题 · 小测”。文件名为“讲义标题-小测”“讲义标题-作业”。

存储上不另建表：小测、作业题和讲义题一样存在这份讲义的条目里，类型为 `quiz`、`homework`，并记着所考查模块的 `moduleId`，统一排在讲义内容之后。服务端保存时，`moduleId` 指向不存在的模块的题改为考查第一个模块。书架列表随每份讲义带回小测、作业的题数（`sheetCounts`）。

## 讲义精排 PDF：配图位置与分页

配图按原题的排法放。Word 导入的题目，题干里的图在原文哪两段之间、印出来多大、怎么对齐，PDF 就怎么排；一行放不下时整行等比缩到版心宽，不再统一挪到题干右侧或末尾。解析里的图也留在原位置（教师版答案框和文末答案）。截图录入的题目按原截图中配图的位置（右侧或下方）和所占行宽比例排。其他题目沿用题干左、配图右等自动排列。

分页时，分节标题和例题／练习／变式标签总跟后面的第一道题在同一页，放不下时一起移到下一页。一道题（题干、配图、选项、考点、作答横线、课堂笔记区）放得进一页就整题不拆开，超过一页才在题内分页。教师版答案框跟在题目后面，答案长时可以接着排到下一页。文末答案中短的条目整条不拆，长解析可以跨页。页眉显示本页最先出现的分节，本页没有新分节时沿用上一页的。填空横线在行末放不下时最多缩短四成，不伸出版心。

公式与正文一样用一套字体排。Word 里用普通文字打出的式子（斜体字母、全角“（）＝﹣：”、上标字）和旁边的 Word 公式合成一个公式排，全角符号换成数学符号，比如“5（3x﹣4）＝…”排成 $5(3x-4)=\dots$。小题序号“（1）”、年份“2026-2027”、百分数和式子前后的标点仍是正文。函数名、单位和 Rt 用正体，其他字母按变量排斜体。含分式的行内公式按 `\displaystyle` 排，分子、分母和正文一样大，与网页、Word 导出的规则一致。省略号“…”按中文字符断行，后面的“，”不会落到下一行开头。

## 工具箱 · 快速排版

快速排版把一份 Word 练习直接排成精排 PDF，题目不进题库。读题和“文件批量录入”走同一条路径（`structuredDocxQuestions`），按 Word 原始结构读出题干、配图、选项、答案与解析，读不出题号时提示改格式。排版用小测、作业的那份练习模板：标题区标签写“练习”，信息栏是姓名、班级、得分，三种答案放法与讲义相同，可下载 PDF 或 TeX 源码。

间距按题型设置，也可以单独改某一道题。解答题设的是作答横线的行数，默认 4 行；其他题设的是题后留白，单位毫米，默认 0。教师版每题后紧跟答案，不留白。预览由 PDF.js 逐页画出，重新排版后停在原来的位置。模板在每道题的题号处放了 PDF 目标 `q1`、`q2`…，预览据此知道每道题在哪一页、哪个位置；点一道题就弹出它的间距设置，改过的题列在左侧，可随时恢复成跟随题型。
