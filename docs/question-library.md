# 题库编号与查找

所有题库模块共用编号，已有题目按创建时间补号，新题由数据库原子分配。编号从 `0001` 开始，至少四位；超过 `9999` 后自然扩展为五位，不截断或复用。

题卡与讲义选题器显示 ID。输入完整 ID 命中题目时跨模块、分类和题型精确查找；未命中则仍按现有范围搜索正文、答案、年份和知识点。

内部 UUID 继续用于讲义与图片关联。`question_codes` 按 UUID 保存独立的永久编号，因为题目表含发布版本且可被物理删除，不能直接用行号稳定编号。编辑、移动、删除恢复、同 UUID 的发布版本均保留编号；导入为新 UUID 的副本分配新编号。编号由服务端控制，不接受客户端指定。永久删除也保留编号映射，避免旧编号指向其他题。

编号唯一性范围为当前数据库内的所有题库；独立部署各自分配，不承诺跨服务器相同。作业批改中的临时题目和学生错题记录不属于题库记录。
