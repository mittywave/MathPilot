# 题库编号与查找

非沉浸页面共用网站顶栏。桌面顶栏高56px，导航保持14px，空间不足时可横向滚动，当前栏目自动进入可视区。外观入口与介绍页顶栏的切换按钮同款：细边圆钮，浅色时显示月亮、深色时显示太阳，点击在浅色和深色之间切换。两套配色取自介绍页：浅色是暖石灰底、墨色字、墨绿强调，实心按钮墨黑；深色是炭黑底、米白字、灰绿强调，实心按钮米白。选择保存在本机，刷新后保留，首次使用跟随系统明暗；介绍页与工作台共用这一个设置，在任一处切换，另一处跟着变。旧的经典深色和科技风设置转为深色，旧多巴胺、可爱风和护眼设置转为浅色。账号显示头像和一行名称，登录同事可退出。嵌套页通过同一顶栏组件提供面包屑和操作区，标签标题使用“当前页 · 上级栏目 · MathPilot”；选中学生时使用“姓名 · 学生档案 · MathPilot”。

产品名统一为 MathPilot。网站首页 `/` 是产品介绍页，题库在 `/library`；以前的 `/?view=…`、`/?studentId=…` 链接转到题库里对应的视图，`/intro` 转到首页。共用顶栏的网站标志在当前标签页回到首页，“题库”导航进入题库。介绍页的“进入工作台”对已登录的老师和本机管理员直接打开题库；没登录时留在介绍页上打开登录窗口，地址变为 `/login`：页面退成一片由同样的沙粒组成的公式（勾股定理、微积分、万有引力、麦克斯韦方程组、E=mc²、薛定谔方程等改变世界的公式，颜色随介绍页浅色/深色），公式在背景中各自缓缓漂浮，鼠标经过公式时像 ∞ 一样散成旋转的沙粒、随后聚回，鼠标在登录窗口上时不拨动背后的公式；沙粒静下来后公式只按半帧率重画漂浮，公式排版（KaTeX）在打开窗口时才下载，首页不预先加载；∞ 的沙粒流成登录窗口的边框，并在窗口里沉积，透过半透明的磨砂玻璃看到。窗口里可以用邮箱和密码登录、用管理员给的邀请码注册，或以访客身份浏览题库，忘记密码由管理员在共享办公里重置；右上角的关闭按钮、Esc 或浏览器后退关掉窗口，沙粒流回 ∞。题库里的“登录 / 注册”、要登录才能用的操作，以及其他页面的“去登录”都打开 `/login`，即介绍页带着打开的登录窗口，登录后回到原来的页面。工具箱卡片、学生档案中的智能组卷、定档到知识图谱和布置完成后的学生档案链接都在同一标签页打开；文件原件、原卷照片，以及知识图谱里的“打开讲义”“在讲义中修改”保留新标签页，避免离开当前图谱视角或未发布的草稿。

介绍页从上到下依次是首屏、01 闭环、02 功能、03 部署和结尾，首屏导航的顺序相同。首屏分左右两栏，上下居中对齐：左栏是小标题、两行大标题“教与学，循环不息。”、一句说明和“进入工作台”“了解功能”两个入口（了解功能滚到 02 功能），右栏是 ∞；底部一条分隔线，左端写 INTELLIGENT MATHEMATICS WORKSPACE，右端的 SCROLL TO EXPLORE ↓ 点一下滚到 01 闭环。首屏与结尾的 ∞ 沙粒沿丝带方向持续循环流动，粒子渐隐接续，保持原有轮廓，鼠标可以拨动；滚动到 01 闭环时，∞ 的两瓣就是两股沙：左瓣是“教”，右瓣是“学”（与首屏 ∞ 背后的两个字对应）。首屏 ∞ 随滚动从交叉点放出沙粒，下半弧先收回，上半弧再收进交叉点，两股沙在交叉点下方拧成一根双股沙绳落下，到正面卡片顶部正中央分开，各自沿上边、一侧和下边铺到底部正中央，合成贴着卡片外沿的一圈沙框；沙框按卡片在透视里的真实轮廓画，跟着卡片一起转动。轮盘每转一步，沙框从顶部正中央开始收拢，沙粒保持原来的顺序、匀速地从底部正中央流出，经过两张卡片之间的双股沙绳（圈数固定，两端都像 ∞ 中间那样交叉换边），从下一张卡片顶部正中央流入再铺开；转到一半时，上一张卡片剩下的下半框、沙绳和下一张卡片的上半框连成一个沙漏。卡片合拢成圆环后，最后一张卡片的沙框从朝向圆心的一边流出，沿一根短绳落进圆环中央 ∞ 的交叉点，先铺下半弧、绕过两端再铺上半弧，重新汇成 ∞，背后是若隐若现的“教学”二字；这一步的进度跟着页面滚动走，这一段滚出四分之一屏时汇完，随后随这一段滚走。进入工作台或打开登录窗口时，沙粒从当时所在的位置出发，转到一半时也不会先跳回某一张卡片。其余时候 ∞ 随首屏移出、随结尾移入，都不在屏幕上时停止绘制。页面隐藏时暂停，系统选择减少动态效果或 WebGL 不可用时保留静态形态。01 闭环是一个随滚动转动的轮盘：这一段钉在屏幕上，七张卡片（入库、组卷、讲义、布置、批改、定档、学情报告）依次转到正面，正面的卡片放大约 1.3 倍。每张卡片是这一步在应用里实际操作的录屏，封面是录屏第一帧；卡片停在正中央后才从头自动播放，转动中、转走后或合拢成圆环时暂停并回到第一帧。录屏在脱敏的数据副本上用脚本操作真实界面录成，AI 结果为在副本上实际调用后回放，等待段剪掉，点击处有波纹；浅色/深色各一套，左下角按钮可暂停/播放，系统减少动态效果时默认不播放。界面改版后用 scripts/record-intro-loop.mjs 重新录制（输出 public/intro/loop 下的 MP4 和封面 JPG）。左边写步骤名和说明，右上角的目录点一下就滚到那一步；滑到最后，卡片合拢成圆环，中央是沙粒汇成的 ∞ 和淡淡的“教学”，入库在顶，左下角出现“七步连成一圈”的说明。02 功能是应用截图沿弧形排开的一行，不再有沙粒轨道。

从介绍页点击“进入工作台”（包括在登录窗口里登录、注册或以访客身份进入）时，先播放约 1 秒的沙粒转场：介绍页的文字淡出，∞ 从当时的形态（首屏、滚动中的轨道、页尾或登录窗框）流成工作台的框架，上半两道弧铺成顶栏分界线、沿两条收起的窄栏流下，下半两道弧泻出屏幕底部，少量沙粒落在题目区；跨页后沙粒框架继续轻微呼吸，覆盖题库首次读取期间的空壳；首屏题目（或确认为空、读取失败的结果）已渲染后，工作台才在同一位置淡入（约 0.45 秒），沙线化成真实的顶栏和窄栏。收尾由真实读取状态触发，不用固定延时猜测加载完成；等待最多 2.5 秒，超时恢复现有加载或错误提示，避免慢请求、脚本异常让页面一直被遮住。访客没有知识图谱窄栏，右侧不留沙线；去往题库以外的页面时只有顶栏线。转场中点击或按任意键立即进入，按 Esc 留在介绍页、沙粒流回；减少动态效果设置下或 WebGL 不可用时直接进入；不支持跨页视图过渡的浏览器（如 Firefox）在沙粒停稳后直接切换。题库先以左右窄栏与首批 8 张题卡展示，后续题卡在淡入结束后再批量补齐，避免渲染挤占入场动画；转场结束、题目首屏出现约 200 毫秒后，知识目录与可用的知识图谱同时自动展开，沿用已有展开动画。此入场效果每次从介绍页进入只播放一次，不改写浏览器记住的侧栏状态；刷新或从其他入口进入题库仍按原有状态显示。等待期间手动操作侧栏或切换栏目会取消自动展开；减少动态效果设置下直接切换。

工具箱目录铺满可用宽度，普通工具与管理员工具分组显示；整张卡片在当前标签页打开。卡片保留名称和简短用途，管理分组只对管理员显示。

界面次要文字至少12px，按钮、输入与路径通常13px；数学内容的层级和装饰符号不按界面小字放大。两套外观的次要文字、强调色与状态文字按4.5:1校验，淡灰文字使用muted或更深的文字色，装饰性边框、图形背景不跟着改深。原生下拉框和勾选控件使用同一外观变量，图谱保留独立深色控件。网页颜色和字号不传入Word、PDF或LaTeX生成器。

工具页使用同一顶栏、面包屑和标签标题。上传作业、文件转录、快速排版、智能组卷及组卷篮采用左控件、右材料或结果的工作台布局；共享办公按共享与邀请码、同事账号分两列，AI配置跟随全站两种外观。组卷篮与智能组卷打开快速排版时使用全屏覆盖层，关闭后回到各自来源并保留标题、顺序和选项。

上传作业、快速排版、智能组卷、文件转录和讲义导出的主按钮缺少材料时，在按钮或操作组下方用12px“还差”行列出待补项，并通过无障碍描述关联按钮。点每项会聚焦并滚动到原有控件；补齐后提示消失，再清空时恢复。文件转录只需原题或答案其中一种，按上传内容自动判断转录方式，已有进度可在任务列表继续，无需重新选原文件；排版的组卷篮来源不要求另传Word。空讲义的提示放在顶条下方，恢复有题状态后仍保持52px工作条。

从学生档案进入上传作业或智能组卷时，面包屑显示当前学生，姓名链接回该生“作业”标签；从工具箱进入时，即使默认选中学生或恢复了学生草稿，也保留工具箱路径。文件转录的原题和答案区在上传或生成 Word 时共同禁用并有离页保护，此时也不会通过账号入口直接退出；文字转录在服务器后台进行，离开页面不受影响。

智能组卷将“已自动保存在本机”和“已保存的方案（在快速排版历史里）”分开显示；右侧空态保留一行说明和唯一的示例填写入口，已有方案使用“方案要点”“用一句话调整”“调整方案”。自动挑题、批改与解答说明不向老师显示内部agent用语，内部标识和模型协议保持原样。

题库发布的任务状态只由已通过发布凭证校验的操作修改。鉴权失败或请求参数错误不会根据请求体中的任务 ID 改写发布状态；合法发布方遇到失败时，沿用已鉴权的失败收尾操作。图片清单比对和最终提交使用单个 JSON 数组参数读取资源，避免图片超过 100 个时突破 D1 的绑定参数上限；缺少图片仍拒绝激活新版本，保留原公共版本。

所有题库模块共用编号，已有题目按创建时间补号，新题由数据库原子分配。编号从 `0001` 开始，至少四位；超过 `9999` 后自然扩展为五位，不截断或复用。

题卡与讲义选题器显示 ID。输入完整 ID 命中题目时跨模块、分类和题型精确查找；未命中则仍按现有范围搜索正文、答案、年份和知识点。

题库模块放在左侧目录中，每个模块显示题数，当前模块展开原有分类树；“模块”标题旁不再放三点菜单，底部统一为“模块与分类管理”。打开后，同一个窗口左侧显示模块及新建、编辑、排序、删除操作，右侧直接显示所选模块的分类及新建、删除操作；选择模块就切换右侧分类，不再进入另一层管理窗口。新建或编辑表单取消、保存后回到这一个管理窗口，备份与回收站入口仍在窗口内。没有模块时仍可从底部打开窗口并新建模块。登录用户可直接拖动侧栏中的整个模块（连同展开的分类）排序，也可拖动每一层知识点，在当前模块内调整顺序、移入其他分类或移回模块根目录，父级知识点连同子分类一起移动；管理窗口内同样可以拖动模块和知识点。条目不显示六点拖拽柄，直接拖动整行，拖动时使用轻量浮层跟随指针，分类行中间表示移入，上下边缘表示插入前后；悬停收起的分类会自动展开，靠近目录边缘自动滚动，松开后保存并以短暂位移动画过渡。按 Esc 或放到无效位置取消，减少动态效果时省略过渡动画；模块排序仍可用管理窗口内的上移、下移按钮。知识点移动复用现有父分类和排序字段，在一次写入中保存，禁止移入自身或子分类（包括并发移动）；所属模块、知识点 ID、题目归属和内容保持不变。指针跟随和落点检测不更新整页 React 状态，只在落下时更新目录。排序保留当前模块、分类、搜索及选题状态，刷新后顺序不变；访客只浏览。桌面端标题右侧的独立按钮可把整个知识点目录收为窄栏，点击窄栏按钮再展开，状态按浏览器记住。顶级模块无论未选中、选中、展开还是收起，左侧始终显示文件夹图标，点击该图标可独立展开、收起；点击已选中模块的名称也可切换展开状态。下级分类仍保留独立箭头，逐级展开、收起；点击未选中的名称仍筛选题目，独立折叠按钮不改变当前分类。层级以高度与淡入淡出过渡，辅以短暂玻璃碎光；整个侧栏收起、再展开时保留层级折叠及目录滚动位置。整个侧栏展开、收起以平滑宽度变化配合短暂的磨砂玻璃光带和细小晶片，静止时不持续播放；系统选择减少动态效果时直接切换。收起不改变分类、搜索、题型和已选题目，隐藏目录不接受键盘焦点；题目列及底部操作栏随左右侧栏宽度一起调整。侧栏保持在顶栏下面，展开时目录独立滚动，底部管理入口始终可用。原说明条、模块卡片和页内重复标题不再显示。

题库页右栏是知识图谱（取已发布的人教版图谱，登录后显示，A-Level 模块不显示），和左侧分类树互相对照。右栏用站点自己的配色，随浅色/深色外观和风格一起切换：底色、文字和连线取页面的墨色，四个领域依次取主色、天蓝、琥珀和紫色，各主题在领域色上深浅错开；左侧点亮的颜色与之相同。标题行右侧的按钮把右栏收起为窄栏，窄栏上的按钮再展开，收起与否按浏览器记住；收起时左侧不再点亮、题卡不再描边，题目列随之变宽。点击题卡空白处、题干、勾选框或“查看解析”后，右栏才切到这道题；单纯悬停或移开鼠标不切换。图谱标出“ID 1123”和它的知识点标签，把第一个知识点的链路抽出展开，前置在下、后续在上，后续超过 18 个时折叠；点击下一题切换到下一题的知识链。题卡和勾选框仍保留原有勾选行为，解析按钮只展开、收起解析，拖选文字不触发勾选或图谱切换。点击图谱画布的空白处回到完整全景，清除图谱的题目定位和目录联动点亮，保留当前分类、搜索及已选题；点击知识点仍沿链路查看，拖动和缩放不触发返回。点左侧分类时右栏转到这一类对应的知识模块：先按分类全名对应图谱的领域、主题或知识点，其次合并下级分类的结果，再按“与、和、及、顿号”拆开逐段对应（如“实数与代数式”对应实数、整式与代数式）；对不上的分类注明“没有对应的知识模块”，点模块本身回到全景。反过来，右栏正在显示的知识点会点亮左侧对应的分类：按知识点、主题、领域依次取最精确的一层，父类只在下级都没对上时点亮；点亮的分类左侧圆点以图谱同色发光。点标签、图中圆点或底部卡片里的前置/后续可沿链路继续查看，分类树随之改变点亮位置。只标到领域的题和对应到领域的分类点亮该领域的主题；没有标签的题提示“这道题还没有知识点标签”。右栏展开或收起时，底部已选题目操作栏都居中于题目列。

搜索、题型、“全选结果 / 取消选中”和 A-Level 语言切换共用一条吸顶工具条。没有题的题型隐藏，“全部”始终显示；切换模块或分类时回到“全部”，按完整 ID 命中时也回到“全部”，以免隐藏找到的题。题型数字是当前分类及其子分类的题数；工具条下方显示当前位置和筛选结果数，跨库 ID 查找单独标明。题库页的题目列表先显示 40 道，往下滚动、离末尾还有约两屏时自动接着显示后面 40 道；换模块、分类、题型或搜索时从头显示。题数、“全选结果”和搜索都针对全部题目，不只是已显示的。每张题卡单独渲染：勾选、展开解析只重画这一张。侧栏分类计数复用一次后代分类查询，不对每道题重复遍历分类树。

点题卡上任意空白处（或题干文字）就勾选这道题，再点一次取消，和左上角的勾选框一样；按钮、链接和“作业批改记录”照旧各管各的，拖选题干文字去复制不会勾选。学生错题本的题卡相同；组卷篮里的题卡不能勾选。
题卡元信息保留 ID、题型和难度；只有搜索、上级分类浏览及组卷篮等需要额外定位时才显示分类路径。在最深分类内不重复当前路径。题卡的“编辑”和三点菜单在悬停、键盘聚焦或菜单打开时显示，不能悬停的输入设备常驻显示；“删除”收在三点菜单内，仍进入回收站。组卷篮的上移、下移和移除始终显示。

删除试题或错题直接进入回收站或历史记录，左下提示中可点“撤销”，恢复原记录，不切换当前模块或学生。批量操作明确说成功与失败的数量，只取消成功删除项的选中；恢复失败时只重试未成功项，列表读取失败则只重新读取，避免重复恢复已成功的记录。管理员也可以在“分类与数据管理 → 回收站”中逐题恢复：题目回到原分类，原分类已删除时回到模块根目录；请求返回前该行按钮显示“恢复中…”，不能再点，避免重复恢复。

全站操作结果共用左下角提示条：成功六秒后消失，鼠标停留、键盘聚焦或执行动作时暂停计时；错误保留到手动关闭，可以附“重试”。提示不再把错误加上成功对勾，英文题库的撤销、重试与关闭名称使用英文。上传、批改、转录、反馈旁的处理状态和错误仍留在表单旁，以13px文字显示，错误用危险色。

选中题目后，底部操作栏显示已选总数、本分类和其他分类的数量，并提示到组卷篮整理；学生错题本则显示该学生和其他来源的数量。按钮从左到右为“删除”“取消选中”“组卷篮”；前两者使用幽灵或描边样式，“组卷篮”是主按钮。“取消选中”会一次清空全部已选题目（包括其他分类中已选的题目），并收起操作栏；只取消勾选，不删除题库题目或错题记录。没有删除权限时不显示“删除”。学生错题本复用搜索、月份分段和选择结果的吸顶工具条。

题库和组卷篮中的题卡将本机管理员录入的题标为“本机管理员 录入”（英文“Entered by local admin”），其他作者有邮箱时照常显示邮箱。作者文字使用 12px 次要文字色，长邮箱可换行，英文题卡也显示作者。题库不显示登录账号后缀，访客保留登录下载入口。

删除模块和学生档案共用站内确认框，列出会一并删除的内容，并输入完整名称后才能确认。打开时焦点在名称输入框，没有名称校验时在“取消”；Esc、关闭和取消都不执行删除，关闭后焦点回到触发按钮。模块删除确认位于管理窗口上层，按一次 Esc 只取消确认。

分类删除会说明子分类及移入回收站的题数；导入备份先读文件，再列出将追加的模块、分类和题数。讲义、空目录、知识模块、临时题、反馈、报告、共享账号管理及AI配置操作复用同一确认框，无法恢复的内容明确说明。知识图谱的放弃草稿、载入历史版本、停用或删除节点、合并节点四类沉浸操作沿用原浏览器确认。

全站表单对话框按 Esc 等同于点击当前最上层的关闭按钮；保存等忙碌状态禁用关闭按钮时，Esc 也不关闭。弹出的菜单先处理 Esc 并把焦点还给菜单按钮，再按一次才关闭底层对话框。中文输入法组合输入时，Esc 只取消候选，不关闭对话框；取消候选后再按一次 Esc 才关闭对话框。点击遮罩不关闭。新增表单对话框沿用 `.modal-backdrop`、`role="dialog"` 和 `button.close`，共用这套行为。知识图谱和编辑器内部的专用弹出层保留各自处理；通用操作菜单复用共享的三点菜单。

内部 UUID 继续用于讲义与图片关联。`question_codes` 按 UUID 保存独立的永久编号，因为题目表含发布版本且可被物理删除，不能直接用行号稳定编号。编辑、移动、删除恢复、同 UUID 的发布版本均保留编号；导入为新 UUID 的副本分配新编号。编号由服务端控制，不接受客户端指定。永久删除也保留编号映射，避免旧编号指向其他题。

编号唯一性范围为当前数据库内的所有题库；独立部署各自分配，不承诺跨服务器相同。作业批改中的临时题目和学生错题记录不属于题库记录。

学生错题本里的题与题库共用这套编号（`0041_question_keys.sql`）。同一道题在作业、错题本和题库里只用一个 ID（`assignment_questions.question_key`，错题记录的 `source_question_id`）：来自题库的题沿用题库 ID；从错题本布置出去的题沿用它在错题本里的 ID；其余的题在第一次判错进错题本时，按题干和选项与老师的题库及所有学生的错题比对，找到同一道题就用它的 ID，找不到才用作业里这道题自己的 ID，并领一个新编号。比对先把题号、全半角、空格、`$`、`\text{}`、`\triangle`/△ 等写法统一；规范化后完全一致，或数字、字母、符号一个不差且文字相似度不低于 0.9（如“一条光线 / 一束光线”）才算同一道题，少于 15 个字的题（离开配图分不清）只认 ID 不认内容。错题本按学生和 ID 去重：同一道题再做错仍是一条，错的次数加一；同一张作业照片重复上传不重复计错。0041 之前的错题由程序在老师第一次读学生档案或错题时按同样规则补号合并：每位学生的同题副本只留一条（优先保留在错题本里的，其次最新的），作业题与错题的出现记录全部改指同一个 ID，在一个事务里完成。老师此前手动删掉的副本是重复上传留下的，并入后标记为已剔除（出现记录的 `evidence_json.dismissed`），不计入错的次数，之后重新批改那份旧作业也保留这个标记；其余副本的错误照常合计。

拍照上传的作业，识别时一并读出题号旁印的 ID（`printed_id`，只认 4–7 位数字，存在这道题的识别记录里）。印的 ID 指向老师题库或错题本里的题，并且照片上读出的就是那道题时——数字逐个相同、文字基本都在那道题里，单独识别的小问只需是它所在大题的一部分——直接按这个 ID 归档，不再比对题干；拍照把数字认错、指到别的题时对不上，退回按内容比对。比对时题干前的来源或分值括注（如“（初一计算1000题第64题）”）不算题目内容，填空横线、省略号的各种写法视为相同。在 961 道真实作业题上回放：同一道题两次识别 519 对、单独识别的小问 188 个全部认得出，随机配成的 118 万对不同题没有一对被当成同一道题（包括只差一个数的计算题）；用真实模型读一张导出的 Word 及其模拟手机拍照，5 道题（含两个小问）的 ID 全部读对并归到原题。拍照上传的题一旦认出是已有的题（按 ID 或按内容），错题本里存那道题本身：题库题存题库原题，错题本里已有的题保留它第一次进错题本时的内容，不换成照片识别出的文字。作业“导出错题”导出的题带上它现在的 ID。

按印的 ID 认出的整题，批改也按那道题来：题型、题干、选项用原题（照片上的作答位置、配图描述和老师的批改符号照旧），参考答案用它自己的——题库题用题库的答案和解析，批改页标“题库答案”；只在错题本里的题，用它进错题本时已经核验过的那个答案。这些题不再让模型解题和核验，所以更快，也不会因为模型现场解错而判错；智能组卷也像对布置的题一样，把它算作这位学生做过的题。题库里答案为空或只写“见解析”的题仍用原题题干，答案由模型解出并核验；单独识别的小问（原题答案是整题的）和 ID 对不上的题，按照片识别的内容解题、核验，与以前一样。老师补充并确认过的参考答案，重新处理时不会被题库答案覆盖。

题库页搜索时，也搜老师所有学生错题本里还没进题库的题（完整 ID、题干、答案、来源或学生名），在题库结果上方单列“错题本中未入题库”，题卡显示 ID、错的次数和做错的学生。悬停后可“加入题库”：打开录题窗口，分类默认是当前分类，学生的原卷照片不带入，配图转存为题库图片；保存时沿用这道题的 ID，编号不变，之后它从这一栏移到题库结果里。错题本的题卡同样显示 ID，错题本搜索也认 ID。

共享操作菜单使用同一种三点图标、尺寸和菜单样式；打开时焦点进入第一个可用项，上下方向键循环、Home/End跳到首尾，Esc关闭并返回入口。表单或确认框打开时保留其焦点，取消后回到菜单入口。知识图谱复用同一菜单交互，同时沿用自身沉浸色系。

## 试卷中心与整卷录入

桌面题库左上角的“模块 / 试卷”按钮将整个目录沿纵轴翻转，两面分别保留目录层级及滚动位置，约 520 毫秒完成；减少动态效果时直接切换。试卷模式自动收起右侧知识图谱，中间显示横向试卷列表；打开试卷时左栏翻回知识目录、图谱展开，中间按原卷题号和分区显示现有题卡。自动收展不改写手动侧栏偏好。点击知识分类转到该分类的全部题目，并保留“返回刚才的试卷”；刷新及浏览器前进后退按 URL 恢复试卷或文件夹。

试卷目录与知识分类独立。初始有“期中期末与统考”（七上至九下）、“中考模拟”（一模至三模）及“自主招生”；普通文件夹可新建、改名、移动层级、上移下移，不能循环嵌套，只能删除空文件夹。上级目录包括所有后代目录的试卷。列表按最新录入排序，每页 40 套，可按标题搜索和按年份、年级、考试类型筛选。每卷可查看、整卷加入组卷篮及下载原件。整卷追加保留已有选题和原题序，相同 ID 不重复勾选；现有排版、导出及布置流程不变。

“录入试卷”使用带文件图标和虚线边框的独立导入区，与文字输入框区分；支持点击选择、拖入，以及弹窗内直接粘贴文件（⌘V / Ctrl+V），普通文字粘贴不被拦截。每次接受一份非空、不超过 80MB 的 DOCX 或 PDF，选定后显示文件名、格式、大小，可更换或移除；选择时即提示不支持的格式、超限或多文件。PDF 可为扫描件；不接收旧 DOC、多张图片或独立答案文件。Word 优先读取原始结构，PDF 在现有后台任务中逐页识别并保存断点。题目跨页时合并续题与配图，答案章按原题号回填；答案页重复印了题干的，回填其答案与解析，不再复制一套题目。没有答案的原卷保持空白，不自行解题。原卷明确标出的笔误及说明保留在识别备注中，不擅自修正题目条件。

Word 题目的网页显示复用已保存的原始段落与图片关系：嵌入式图片按原位置出现在题干、解析和表格单元格中，保留原尺寸、段落对齐和合并单元格；已在正文显示的题图不再重复放到题尾。仅有图片的段落或表格也保留。没有原始结构、未被结构引用或网页暂不支持定位的浮动题图继续使用配图区。已录入且保留原始结构的题目刷新即生效，无需重录；不改写题库数据，Word 导出继续复用原始结构。

试卷文件夹默认“自动按试卷标题归档”。上传时先按文件名显示暂存位置，完整识别后以原卷标题和已提取的年级、学期、考试类型匹配现有目录，支持七上至九下、一模至三模、自主招生及标题明确包含的自定义文件夹路径。信息不足时只放在匹配的上级目录；完全无法匹配时暂放“期中期末与统考”（该目录不存在时使用首个顶层目录），不自动新建文件夹。手动指定的文件夹不被后台覆盖；自动模式保存在现有试卷元信息中，重试与修正时保留，旧试卷保持原有手动归档行为。编辑试卷也可切换自动或手动；自动录入后返回全部试卷，避免最终归档后任务从暂存目录消失。

系统自动提取卷名、学校、地区、学年、年级学期及考试类型；不明确的信息留空，可在三点菜单中编辑或移动试卷。校内卷、月考周练、统考、中考真题及模拟卷的新题进入“初中数学”，首次需要时建立；自招卷进入“自主招生”，其他考试可指定现有模块。逐题优先匹配现有知识目录，参考已发布知识图谱的标准名称，必要时补建分类；不会自动修改图谱本身。同题复用原 ID 和原归属，不因试卷来源另建副本或无用目录。

题干、选项和配图必须严格匹配才共用 ID，不采用模糊匹配合并变式。已有非空答案和解析保留，缺失字段可补充；内容冲突、题号歧义、漏题或不完整续题会保留任务，显示具体问题，提供“继续 / 修正”。完成上传后可离开页面；完整校验通过后，一个 D1 事务提交新增模块、分类、题目和试卷引用，中途失败、取消或重复投递不会发布半套试卷。重复上传同一文件返回已有试卷或任务。

试卷只保存元信息和有序题目引用（UUID、原题号、分区、页码），题目正文仍在共享题库。编辑共享题目后，各试卷显示最新内容，上传原件保持原样。删除试卷只删除试卷及其原件，题库题目保留；题目进入回收站时保留缺失题位，恢复后沿用原 ID。访客可浏览，登录教师可录入、编辑、选题及下载，管理员可删除。表为 `paper_folders`、`exam_papers`，原件在现有 R2 的独立 `papers/` 路径，识别复用 `studio_jobs`；现有题库 JSON 备份仍只包含模块、知识分类和题目，不包含试卷原件及试卷目录。

## 讲义书架

讲义只有一种，按存放位置分在三个书架上，编辑器和导出都一样：

- **课程体系**：可以建立多套体系，按「体系 → 年级 / 阶段 → 学期 / 单元 → 每一讲」编排。前三层名称和数量均可自定义，支持改名和上移、下移；每讲的编号由所在单元内的顺序决定。全员共用。
- **专题库**：与“课程体系”是同级书架，按「专题库 → 专题分类 → 大纲目录 → 专题分组 → 每一讲」编排，不分年级。函数、几何等分类对应“深圳创新体系”；其下左侧缩进列出“二次函数”等大纲目录，对应“初一”等阶段。选中二次函数后，右侧以“函数”为标题、显示当前目录名，并列展示“二次函数的性质”“二次函数的图像”等专题分组，每组可放多份讲义。分类、大纲目录和专题分组均可改名、排序，空目录也会保存。左侧“专题库”标题右侧的 ＋ 创建分类，分类下的“添加大纲目录”创建左侧目录，选中目录后右侧的“添加专题”创建分组。分组内按顺序添加第 N 讲，复用课程体系的标题和模块大纲填写流程。原有五个分类保留，全员共用。尚未分类的旧讲义仍在“未分板块”；分类直属讲义在分类总览的“未分目录”，旧系列作为大纲目录保留，直属讲义在目录内的“未分专题”。旧讲义可移入具体专题，移空后对应入口或列消失。
- **学生讲义**：挂在学生档案下，只有这位学生的老师能看到、编辑和删除；删除学生时，这位学生的讲义一起删除。

书架由讲义的存放字段推出，不另设类型：有学生的是学生讲义，有关联课程单元的是课程体系，其余都在专题库（按分类、大纲目录和专题分组，没有分类的是未分板块）。共享讲义只有管理员能删除。

讲义书架页不再重复页面标题。左侧是书架导航，顶部可以按讲义标题或模块名查找全部书架；右侧用满整个宽度：课程体系并排列出所选阶段的各个学期或单元，专题库并排列出所选大纲目录下的专题分组，学生讲义列出这位学生的全部讲义。每条讲义显示课次号（课程单元或专题分组内）、标题、各模块名（模块之间用“；”分隔，因为模块名本身常带“、”），只在有题时追加“讲义4 · 小测3”等非零数量，完整三项数量保留在无障碍名称中；列头显示总讲数和已有内容的讲数。上移、下移、复制一份、移到…和删除收在三点菜单里。侧栏数量和操作共用行尾，鼠标经过、键盘聚焦或菜单保持打开时切换，行宽与文字位置不变；不支持悬停的桌面输入设备同时显示数量和操作。只给最深的年级或大纲目录行铺选中底色，所属体系或专题分类只加粗。新建体系和新建专题分类入口分别位于“课程体系”和“专题库”标题右侧。每一列末尾是“添加第N讲”或“为某某新建讲义”。“移到…”可以在课程体系（选择完整的体系 / 阶段 / 单元路径）、专题库（选择专题分类 / 大纲目录 / 专题）和自己的学生之间移动，移到学生名下后只有自己能看到。课程单元与专题分组分别列出，互不混入目标列表。编辑页底栏的返回链接写明讲义所在位置，如“深圳创新体系 / 初二 / 秋季”“函数 / 二次函数 / 二次函数的性质”或学生姓名，并回到对应大纲目录；刷新也恢复所选目录。

点击「新建体系」后，依次添加年级 / 阶段、学期 / 单元。添加一讲时填写标题和模块大纲（每行一个模块），可以「保存大纲」继续安排后续课次，也可以「保存并编写讲义」进入现有编辑器。大纲模块直接成为讲义里的知识模块，没有另一份待同步的大纲正文；后续在讲义里修改标题、模块，目录立即采用保存后的内容。每讲继续包含讲义、小测、作业。复制讲义后可以跨体系移动，源讲义独立保留。刷新以及从编辑器返回，会恢复所在体系和阶段。

空体系、空阶段、空单元、空专题分类、空大纲目录和空专题分组也持久保存。目录和讲义均使用稳定 ID，改名、排序不改变内容关联。同一父目录下名称不能重复；不同大纲目录可使用相同的专题名。删除目录只对管理员开放，并且必须没有下级目录、没有讲义，不能连带删除内容。保存失败时保留表单输入供重试。

`0035_handout_courses.sql` 将原有三个年级、四个学期迁入默认的「深圳创新体系」，保留全部讲义 ID、内容及顺序。`handout_course_nodes` 保存三层目录，讲义用 `course_unit_id` 指向单元，取代旧 `grade` / `term` 列，专题及学生位置不变。旧浏览器发送年级 / 学期的写请求会被拒绝，刷新后使用新目录。原有深圳创新知识图谱仍关联默认体系的三个原始阶段；新建体系的模块不会自动混入该图谱。

`0036_handout_topics.sql` 在同一目录表内加入专题库根目录和五个初始分类。大纲目录与专题分组复用这棵树，不新增表、列、接口或迁移，不批量移动旧讲义。讲义的 `domain` 指向专题分组的稳定 ID；旧分类及大纲目录直属讲义继续兼容读取，ID、内容和顺序不变。接口验证专题位置存在，并拒绝把专题目录当成课程单元；非空目录不能删除。返回数据沿用 `coursePath` 承载共用目录路径，专题展示时省略“专题库”根节点。专题路径含根节点最多四层，课程体系仍严格三层，不能因为专题多一层而扩大课程层级。原有 `topic` 地址参数和本地存储继续使用所选目录 ID，不另设平行的选择状态。课程知识图谱的五个领域保持独立，专题目录改名和增删不改变图谱领域。

## 讲义内选题

打开一份讲义后，桌面端采用左侧选题、中间正文、右侧结构的三栏布局；选题与正文约2:3，三栏独立滚动。顶部52px工作条固定显示返回书架的24px标志和已有位置路径，右侧是保存状态及导出；失败显示红点和重试，所有桌面宽度下位置一致。讲义标题放在正文栏顶部，标签标题使用“讲义标题 · 讲义编撰 · MathPilot”。正文及导出内容和排版保持原样。

桌面编辑页最右侧增加“讲义结构”导航，按正文顺序显示讲义标题、知识模块、知识点入口及例题／练习／变式题号，编号复用正文规则。小测、作业切换为各自的结构和连续题号。点击标题、模块、知识点或题号平滑定位正文，键盘焦点随之移到目标。结构直接由当前讲义内容生成，编辑标题、增删或调整题目后同步更新，不另存一份大纲。

结构栏中的题号可直接拖动。拖到另一模块的标题或空白处，保留例题／练习／变式用途并追加到该模块；空模块也可接收。拖到已有用途分区或题号前后，则按落点的用途和顺序放置。模块落点高亮，题号前后显示插入线。结构栏和正文六点手柄复用同一移动逻辑，可相互拖放；移动后正文与结构栏同步重编号并自动保存，不复制题目。小测、作业题号只在各自列表内排序；题号聚焦后可按 ↑ ↓ 调整本栏顺序，点击仍用于定位。

左侧题库与右侧结构栏均可通过各自右上角的侧栏图标独立收起、展开，收起后保留带短标签的窄栏，把空间让给正文；开合状态保存在本机。两侧采用同步的宽度、淡入淡出及轻微位移过渡，收起时内容保持原宽度，搜索、筛选、待选题和滚动位置保留。隐藏内容不进入键盘或读屏导航；系统开启“减少动态效果”时关闭过渡与平滑滚动。正文的“从题库选题”“替换”和空资料的“至少一道题”入口会自动展开题库。

题库、正文、结构栏之间的两条分界线支持拖动调宽，悬停或键盘聚焦时显示高亮。拖动只调整相邻侧栏与正文，另一侧保持宽度；拖动时直接更新布局，松手后与开合状态一起记在本机，收起再展开恢复自定宽度。窗口变窄或展开题库内部目录时临时限制三栏最小可用宽度，空间恢复后恢复偏好。双击分界线恢复对应侧栏的默认宽度，左右方向键微调（Shift 加大步长），Home / End 调到当前允许的最小 / 最大宽度，Esc 取消本次拖动。收起的侧栏不显示拖动条。

选题区复用题库页的知识目录与试卷中心。正式题库的左侧目录显示全部模块，分类可逐级展开、收起；点击分类筛选题目，点击模块根目录查看该模块全部题目，再次点击当前分类或模块可折叠其子级。“模块 / 试卷”标题旁的独立 ⇄ 按钮将目录沿纵轴翻转，复用约 520 毫秒的过渡及减少动态效果规则。两面各自保留目录层级和滚动位置，隐藏面不进入键盘或读屏导航。

试卷面使用同一文件夹目录、标题搜索、年份／年级／考试类型筛选、分页、录入、下载原件和管理菜单。查看试卷后目录翻回模块面，选题区保留原卷题号、分区和不可用题位；点击知识分类可查看该分类全部题目，并通过“返回刚才的试卷”回到原卷。URL 沿用 `view`、`paperId`、`folder` 和 `returnPaper`，与讲义 ID、当前资料并存，刷新及前进后退恢复选题位置。试卷列表保持挂载，返回后保留搜索及筛选。

试卷内可逐题选择；“整卷选择”按原卷顺序追加到当前待选，保留此前选择、去除重复并跳过当前资料已经使用或不可用的题目，再通过原有“加入例题／练习／变式／小测／作业”按钮确认加入。替换模式只允许逐题替换。试卷题与知识目录题使用同一永久 ID 和正式题库，不另存副本。临时题库沿用原有导入、校对和入库流程。

目录标题行最右侧的左箭头用于收起，选题来源左侧的右箭头用于展开；图标按钮提供悬停提示和无障碍名称。内部目录同样使用约 480 毫秒的宽度、淡入淡出和轻微位移过渡，目录内容保持固定宽度，选题区与展开按钮同步平滑让位；支持快速反向切换。知识目录、试卷目录及临时题库说明共用此动效，隐藏内容保持挂载以保留层级、筛选、待选和滚动状态，同时退出键盘及读屏导航；切换后焦点移到对应的开合按钮，减少动态效果时立即切换。1440宽默认收起，1680及以上默认展开。模块和分类以 `mathpilot-picker-scope` 记在本地，下次打开任意讲义恢复，失效选择回到现有模块，存储不可用时仍能继续选题。完整 ID 搜索可跨模块查题。选题卡通过自身容器宽度把四个选项从一行改为两列，再不足时一列；很窄的题卡将右配图改为上下排列，避免题干挤成竖行。只影响选题区网页显示。

选题区用“加入到 模块一 · 例题”标签写明目标，模块和用途选择器始终直接显示，不提供折叠按钮；点击标题、按 Esc 或点击外部都不会收起选择器。点正文某栏的“从题库选题”会切换目标并短暂高亮，减少动态效果时不播放动画。小测和作业始终显示加入的资料及考查模块选择器。指定目标后批量选择并加入，已在当前资料中的题目不可重复加入；加入后保留筛选条件和目标位置，清空本批选择。导出是工作条上的主按钮，加入所选使用次按钮。

编辑页铺满整个窗口。右侧讲义按成品的样子排：标题下是各知识模块，模块序号和精排 PDF 一样做成圆角色块，上移、下移、删除模块收在模块标题行的“更多”里。每个模块依次是知识点、例题、练习、变式，每一段是一个圆角框：带底色的标题栏写段名，题数用圆形徽标（有题时实心，没有题时是空心灰圈），没有题的段只剩标题栏。编辑页不显示印在 PDF 和 Word 里的引导语，也没有空白提示框。知识点编辑框嵌在本段的框里，编辑时整段描边。每段标题栏右侧是“从题库选题”“录入新题”两个文字按钮，正在接收左侧选题的那一段整框描边。题目之间用细线分隔，题目下方一行写题型、所在分类和考点（没有考点时可直接补充），右侧是替换、更多和红色的“移出讲义”。鼠标经过题目时左上角出现六点拖动手柄（像 Notion）：按住拖到另一道题的上半或下半松开，就放在它前面或后面，可跨段、跨模块，放进哪一段就改成哪一段的题；拖到某段的空白处则排到该段末尾。小测和作业的题只在本列内拖动。手柄获得键盘焦点时按 ↑ ↓ 在本段内移动一位。

右侧各栏的“从题库选题”会定位左侧并切换加入位置；“替换”在左侧选一道题替换，保留原位置和用途，也可取消替换。题目卡片上直接显示红色“移出讲义”按钮，点一下即从讲义移除，题库原题不受影响；改为其他用途、编辑原题放在“更多”里。删除目标模块后，加入位置回退到第一个现存模块；无模块时需先添加知识模块。宽度不超过 1200px 时隐藏知识目录（仍可搜索分类名），返回、保存状态和导出移到题库顶部；不超过 900px 时上下排列，题库结果区仍独立滚动。讲义列表、知识点编辑、自动保存及导出规则不变。

## 临时题库

左侧「正式题库 / 临时题库」切换选题来源。临时题库属于当前这一讲，讲义、小测、作业共用，随讲义自动保存，刷新或重新打开后仍可继续编撰，复制讲义时一并复制。切换来源清空本次待选，不影响已经加入的题目。

「导入文件」复用智能录题的校对界面，支持 Word（.docx）、PDF、PNG / JPEG / WebP 图片，也可拖入文件、粘贴图片。Word 优先读取原始题干、公式、表格、配图和解析，读得出就直接进入校对；PDF、图片和读不出结构的 Word 交给 AI 在后台逐页识别：页面上传完就可以关闭窗口，导入窗口下方的“识别任务”列出进度（识别中带脉动绿点，可取消、继续、删除），导航“题库”旁的数字显示正在识别的文件数；识别完点“打开”进入同样的校对界面。某页多次重试仍失败时任务停下并写明页码，“继续”只重识别这些页，已识别的页可以先打开校对。页面图片和识别结果保存在服务器上，删除识别任务时一并删除。校对确认后先进入临时题库，再选择加入哪个模块及例题／练习／变式，或当前小测、作业；默认不入正式题库。原有右侧「录入新题」继续直接保存到正式题库并加入当前资料。旧版 .doc 须另存为 .docx；单个文件上限 80MB（读不出结构的 Word 最多转换 80 页），图片上限 15MB。

Word 先按文件自身结构读题，读得出就不调用 AI：除了“一、选择题”这类大题标题下的“1．”“2．”题号，也认讲义里单独一行的加粗标题（“例题精练 1”“知识拼接2 1”“例题 6-1”，文件转录导出的 Word 就是这样），标题下面的段落就是题干。这种讲义没有题型分区，题型按内容推断（有 A、B 选项为选择题，有横线为填空题，其余为解答题），校对时提示核对；没有编号的加粗短行（如讲次“五心综合”）结束上一题。旧式 VML 配图（`v:imagedata`）读成普通的嵌入图片，网页题卡、Word 导出和讲义 PDF 都按原位置显示；配图上用 Word 绘制的线条或标注读不出来时提示核对。题库照原段落复现 Word，所以文件转录导出的 Word 照原件排，不另加版式：小问编号后直接接正文，不加制表符；原题配图按它在原页上的位置靠右、居中或靠左（这类讲义多是题干下靠右），原页同一行的几张图放在同一段里并排；大小按它在原页一行里占的比例，至少四成行宽、最高 240 磅，与 Word 和精排 PDF 中独立单图的规则一致。题干开头印着的原题号（如“2.”）写成一段文字，题库才认得出，导出时换成卷面题号。文件转录导出的红字解析读入“解析”，“转录提示”“格式问题”读入核对提示；只有解析、没有题干的题默认不勾选。同名标题或重复的局部题号各自带自己的配图和解析，答案区按题号回填只用于唯一的题号。Word 导出时，题干开头印着题号的改成卷面题号，开头没有题号的（讲义标题导入的题）在开头补上卷面题号。

Word 读不出题目结构时，才把整份文件转成页面图片交给 AI。转换前先把 VML 配图换成普通图片；每页由浏览器自己画成图片（SVG foreignObject），Word 公式和配图都按浏览器显示的样子画进页面，不再像 html2canvas 那样公式空白、中文偏低。随页面一起交给 AI 的文字提示里，公式写成 `$LaTeX$`（与网页题卡同一套转换）。画进页面的公式数、图片数与 Word 原件对不上时，校对界面的“导入提示”逐项写出缺了多少，不会把转换缺失当成原件没有。浏览器不允许这样画页面时（如部分 Safari），退回 html2canvas，并提示公式只以文字交给 AI、建议改用 Chrome 或 Edge。

PDF、图片按页批量 AI 识别时，题号不当作题目的唯一标识：讲义各栏目常从 1 重新编号（例题精练 1…、知识拼接 1…），同题型同题号的题全部保留，只按题干去掉完全相同的重复。只有某页第一题与上一页最后一题题型、题号都相同时，才可能是跨页重复识别：这道题默认不勾选，并提示核对。答案区、Word 解析等按题号给出的内容，只填给唯一一道该题号的题；有多道同号题时不自动填入，在这些题上提示对照原件核对，不会把后一栏目的答案填到前一栏目的同号题上。

临时题卡可单独校对或删除；已被本讲任何一份资料使用的题必须先移出，才能从临时题库删除。按来源文件、题型或关键词筛选。入库与选题是两个独立操作：勾选「存入正式题库」，选择目标分类，再点「保存勾选 N 题」。只保存勾选的题，已入库题标记并禁用重复入库；部分失败仅重试未成功的题。临时题保留本讲的快照，后续校对不会修改已沉淀的正式原题。删除整讲时也删除其临时题库，正式题库中的原题不受影响。

存储复用 `handouts.items_json`：没有临时题时仍写原数组，有临时题时写 `{ items, temporaryQuestions }`。读取兼容原数组，省略 `temporaryQuestions` 的旧客户端更新保留已有临时题；讲义目录摘要不携带临时题正文。最多 400 道临时题，总内容受 D1 单行大小限制，配图复用现有分块素材存储。正式题导出继续校验题库权限，临时题由当前讲义读取权限控制，并使用同一网页显示、Word / PDF 排版路径。

外部 Word 的题干经校对修改后，题干原始 XML 与旧段落缓存同时失效，网页与导出均使用修改后的内容。小数开头的独立计算行仍属于当前题干或解析，不视为下一题题号。Word 导出保留原生公式；对原件把公式嵌入文字运行节点的非标准结构，提升至合法的段落子节点，保留前后文字与格式，避免公式在 Office 渲染器中消失。

## 一讲三份资料：讲义、小测、作业

每一讲（书架上的每一份讲义）有讲义、小测、作业三份资料，共用标题、书架位置和课次。编辑页标题右侧切换三份资料，每份旁边是题数徽标；地址记住打开的是哪一份（`?sheet=quiz`、`?sheet=homework`），刷新或打开链接回到同一份。

- **讲义**按知识模块编排，规则见上。
- **小测和作业**各是一列题，编号 1、2、3…，没有例题、练习、变式之分。每道题下方的“考查”选择它考的是本讲哪个知识模块。左侧题库的加入位置写成“加入小测，考查［模块］”，新加的题默认考查这个模块；“录入新题”录好的题加到当前这一份。上移、下移只在本份资料里换位置；“替换”保留位置和考查模块。
- 一道题在同一份资料里只出现一次；在本讲另外两份资料里用过的题，左侧标出“讲义已用”“小测已用”等，但仍可以选。
- 删除知识模块时，讲义里这个模块的题随模块一起移出；考查这个模块的小测、作业题保留，改为考查前一个模块（删的是第一个模块时改为后一个，一个模块都不剩时显示“未选模块”），删除前会提示。复制一份讲义时，小测、作业题考查副本里对应的模块。
- 从课程知识图谱的节点卡片点“打开讲义”时，地址带 `?module=`：编辑页滚到这个模块，左侧题库的加入位置也指向它。
- 导出的是当前打开的那一份。小测、作业的精排 PDF 标题区标签写“小测”“作业”，信息栏是姓名、班级、得分，只排题目、不印考点；答案的三种放法和讲义相同，学生版给解答题留作答空间。Word 标题为“讲义标题 · 小测”。文件名为“讲义标题-小测”“讲义标题-作业”。

存储上不另建表：小测、作业题和讲义题一样存在这份讲义的条目里，类型为 `quiz`、`homework`，并记着所考查模块的 `moduleId`，统一排在讲义内容之后。服务端保存时，`moduleId` 指向不存在的模块的题改为考查第一个模块。书架列表随每份讲义带回小测、作业的题数（`sheetCounts`）。

## 讲义精排 PDF：配图位置与分页

配图按原题的排法放。Word 导入的题目，题干里的图在原文哪两段之间、印出来多大、怎么对齐，PDF 就怎么排；一行放不下时整行等比缩到版心宽，不再统一挪到题干右侧或末尾。解析里的图也留在原位置（教师版答案框和文末答案）。截图录入的题目按原截图中配图的位置（右侧或下方）排。Word 和精排 PDF 中，独立单图至少按四成行宽安排，右侧配图最多占四成半，避免照搬整页照片中的小图比例；宽图仍保留更大的原占比，并受最大高度约束等比缩放。Word 的题干与后续独立配图保持相连，避免题图单独落到下一页。高清重绘配图从已保存的矢量稿生成打印副本，线条至少为图宽的 0.6%，灰黑线条和点名用黑色，有色图保留颜色；网页与已存原图不变。普通裁图、照片、Word 原位嵌图沿用原图片。其他题目沿用题干左、配图右等自动排列。

分页时，分节标题和例题／练习／变式标签总跟后面的第一道题在同一页，放不下时一起移到下一页。一道题（题干、配图、选项、考点、作答横线、课堂笔记区）放得进一页就整题不拆开，超过一页才在题内分页。教师版答案框跟在题目后面，答案长时可以接着排到下一页。文末答案中短的条目整条不拆，长解析可以跨页。页眉显示本页最先出现的分节，本页没有新分节时沿用上一页的。填空横线在行末放不下时最多缩短四成，不伸出版心；换到下一行时整条留在行首，不会被当成行首空白丢掉。

作答横线（练习、变式、小测、作业的解答题）和例题的课堂笔记区按同一行距画线，1 行 = 8mm，每条线在一行的底边，行距精确，不受字号和行高影响。解答题默认 6 行。一页的最后一块内容是印了作答横线的题时，这道题的横线按同样的行距、缩进和宽度一直画到版心底边。下一题放不下移到下一页，或者这是最后一道题时，页底都不再留大片空白。分页先由 TeX 定好，横线只补在页底剩下的地方，所以分页不变。课堂笔记区是固定大小的框，不延伸。教师版没有横线，文末答案页也不延伸。做法：每道题结束时在独立的 mark 类（`\newmarks`）里记下它横线的缩进和宽度，没有横线记空；分节、段标签、答案标题也记空。`\@texttop` 量出本页内容的自然高度，`\@textbottom` 看 `\botmarks`，决定是否补线。

公式与正文一样用一套字体排。Word 里用普通文字打出的式子（斜体字母、全角“（）＝﹣：”、上标字）和旁边的 Word 公式合成一个公式排，全角符号换成数学符号，比如“5（3x﹣4）＝…”排成 $5(3x-4)=\dots$。小题序号“（1）”、年份“2026-2027”、百分数和式子前后的标点仍是正文。函数名、单位和 Rt 用正体，其他字母按变量排斜体。含分式的行内公式按 `\displaystyle` 排，分子、分母和正文一样大，与网页、Word 导出的规则一致。省略号“…”按中文字符断行，后面的“，”不会落到下一行开头。

## 工具箱 · AI 配置

管理员在工具箱的管理分组看到“AI 配置”卡片，点击后在同一标签页打开现有 `/settings/ai`，管理服务连接、模型目录、任务分配和连接诊断。配置页通过统一顶栏回到题库或工具箱；连接、任务分配或模型编辑有未保存修改时，离开或刷新前提示确认，取消后保留草稿。普通成员和访客不显示此管理入口，服务端沿用管理员权限校验。

## 组卷篮

组卷篮左侧是桌面结构目录：练习标题标签与输入框同行，单行答案选项紧凑放在下方，中间目录独立滚动并优先占用可用高度；下方用一行显示题数与保存状态，快速排版和生成 Word 缩为 32px 高的并排按钮，更多菜单放在同一行并向上展开。每份卷只有一层大标题，可新增、改名、折叠及拖动排序；空组保留编辑，但不打印也不占大题序号。各组以虚线分隔，标题右侧显示题数；组内以 4px 间隔从左连续排列 32px 方形题号，并按可用宽度自动换行，不再重复题库 ID 和题干，空组仅保留标题和 0 题，不重复占用一行操作提示。点击题号会加载并定位右侧题卡，包括尚未显示的第 40 题之后的题目。

当前题默认是第 1 题；点击左侧题号或中间题卡空白处即设为当前题，左侧题号填成实心（悬停时也不变），题卡加绿框，题量多时左侧目录自动滚到当前题号。

题号本身可拖动排序或跨组；拖动时原题淡化，根据指针所在题号的左右半区及换行位置显示绿色插入线，题号间隙也按相邻位置插入。松开后被移动的题号高亮两秒，结果提示写明原题号、目标分组及新位置；原位放下提示位置未改变，取消拖动不改顺序。精确上下移和“移动到”归组使用右侧题卡的原有控件，上下移只在当前组内生效。题库和学生错题本新选的题目一律追加到“未分组”，不改变已有归属。大标题右侧直接显示红色垃圾桶按钮，悬停提示“删除标题，题目移回未分组”，点击即删除标题，组内题目按原顺序追加回未分组，不取消选择；大标题通过左侧手柄拖动排序。清空组卷篮则同时清空题目和标题。题库底栏的“取消选中”仍只取消所有题目，保留空标题。

“按题型分类”是一次性整理，按单选、多选、填空、判断、解答依次建立非空组，组内保留当前题序；整理后仍可改名和自由挪题。已有标题时先确认替换标题和归属，取消则保持原结构。右侧、Word 和快速排版 PDF 使用同一份大标题、顺序和全卷连续题号；大题序号自动生成。存在自定义组时，未分组题目在卷末列为“其他题目”；没有自定义组时沿用普通试题列表。文末答案重复大标题，小题编号与正文一致。

浏览器 IndexedDB 按账号自动保留一份本机草稿，包括标题、结构、题目引用、已选错题快照、答案选项和快速排版设置，不进入云端历史。刷新后先读完草稿再启用自动保存；题库原题使用当前可见版本，失效引用移除并提示。错题快照随草稿保留，移除题目后不再保存该快照。退出登录清除内存中的题目和设置，原账号的本机草稿继续保留；其他账号使用自己的草稿。本机读取或保存失败会提示，页面中的整理和导出仍可用；读取失败时不覆盖原记录。

## 工具箱 · 快速排版

快速排版把一份 Word 练习直接排成精排 PDF。仅排版、下载且不勾选入库时，题目不进题库；确认布置给学生时，每题自动加入题库并分配永久 ID。读题和“文件批量录入”走同一条路径（`structuredDocxQuestions`），按 Word 原始结构读出题干、配图、选项、答案与解析，读不出题号时提示改格式。排版用小测、作业的那份练习模板：标题区标签写“练习”，信息栏是姓名、班级、得分，三种答案放法与讲义相同，下载 PDF。

Word 中的图片选项保留 A–F 标签及原图尺寸，纯图片和图文混合选项按原顺序显示；导入校对、题库卡片和 PDF 共用选项结构，Word 导出沿用原始选项段落，不再把选项图当题图重复放大。解析中的连续数字列举（如“0、4、8、…”）保留在当前题中，不作为新题号截断答案。

也可以点“粘贴网页题目”，复制网页内容后在粘贴框按 ⌘V / Ctrl+V，粘贴后自动排版；聚焦 Word 选择区域时也可直接粘贴。多道题保留「1.」「2.」等题号，没有题号时按一道题读取。支持纯文字、LaTeX / MathML 公式、上下标、表格和可读取的网页配图；题后答案与解析、按题号列在文末的参考答案沿用三种版本的放法。文末答案遇到重复题号时提示分段粘贴；识别到配图但读取失败会提示改用 Word，避免漏图。粘贴内容在本机规范成 Word，复用同一条读题、PDF、历史记录和布置作业路径，不新增题库题目。标题默认为“网页粘贴练习”，可直接修改。

快速排版中已有题库编号的题目，在题号后、题干前打印 `ID 0046` 这样的编号标志，便于后续批改时定位题库答案与解析。学生版、附答案版、教师版均显示；按章节、按天分组及调整题序后仍使用原题的永久编号，不用卷内题号代替。外部 Word 中未入库的题目没有题库编号，不生成虚假 ID。“显示题目来源”旁提供“加入题库并分配 ID”勾选框，默认关闭；勾选后立即入库并重新生成带 ID 的预览和下载 PDF。取消勾选不会删除已入库题目或撤销永久 ID。确认布置给学生时无论是否勾选都先入库，入库失败不继续布置。新题保留原有模块与分类，未分类题进入题库第一个现有模块的根目录；没有模块时提示先创建模块。相同题目内容使用稳定标识，重新打开原 Word、重试或再次分发复用原 ID；已印 ID 的 Word 核对题库原题后复用编号。左侧版本设置下提供“显示题目来源”勾选项，默认关闭，开启时来源标签排在 ID 后；切换来源显示不影响 ID。来源显示和入库选项与其他排版设置一起保存在组卷篮本机草稿或当前历史记录中，重新打开时恢复。

组卷篮、讲义的小测 / 作业单列和作业“导出错题”导出的 Word 同样在题号后印 ID（灰色小字加细边框，与 PDF 一致），讲义正文的例题、练习与讲义 PDF 一样不印。这样的 Word 再读入（快速排版、录题、讲义导入）时，题号后的 ID 从题干里摘出、记为这道题的编号，快速排版重排的 PDF 照样印出；原样段落里没能摘掉的，再导出时不印第二个。图片 / PDF 识别录题也不把印的 ID 写进题干。

组卷篮里点“快速排版”，在原页面打开同一个工具，题目直接用题库原题，不经过 Word。标题和章节顺序沿用组卷篮；第一次打开时，勾选“附带答案与解析”是附答案，不勾是学生版。章节采用自然分页、全卷连续编号，标题区保留姓名、班级、得分，不显示分天的日期、用时和做对数量。工具里修改的标题、版本和间距同步保存到本机草稿；左上角“← 组卷篮”或来源卡片返回继续整理。单题间距只在题目和顺序都未改变时保留，单纯改标题或归组且题序未变时保留。打开前和生成 Word 一样先校验下载权限。

间距按题型设置，也可以单独改某一道题。解答题设的是作答横线的行数，默认 6 行，是最少行数，每页最后一道解答题的横线还会画到页底；其他题设的是题后留白，单位毫米，默认 0。横线行距默认 8mm，可在 6–12mm 之间调。间距数字输入时可以暂时清空，数值仍实时更新排版；按 Enter 或离开输入框后显示允许范围内的整数并去除前导 0，留空离开时恢复上一次有效值。教师版每题后紧跟答案，不留白。预览由 PDF.js 逐页画出，重新排版后停在原来的位置。模板在每道题的题号处放了 PDF 目标 `q1`、`q2`…，预览据此知道每道题在哪一页、哪个位置；点一道题就弹出它的间距设置，改过的题列在左侧，可随时恢复成跟随题型。

历史记录：快速排版排过的资料按账号存在服务器上，每位老师只看得到、改得到、删得到自己的。打开一份新的 Word 就新建一条记录，记下原始 Word、标题、题数和排版设置（版本、题型间距、单题调整、横线行距）。之后改标题或任何设置，一秒后写回这条记录，最近编辑时间随之更新。页面左上角的“历史记录”打开列表，按最近编辑排序，每条显示标题、文件名、题数、版本、最近编辑时间和首次排版时间；没打开资料时列表就是首页。点一条就按当时的设置重新读出原 Word、排出 PDF，可以接着调整；只打开不改动不算编辑。删除要点两次确认。
智能组卷的方案也存在这张历史表里（见下节），列表中显示“智能组卷 · 学生名 · 分 N 天”而不是文件名；点开时按题目 ID 从题库取原题，已被删除的题跳过并提示，来源卡片可回到智能组卷调整题目。
布置给学生：组卷篮的章节试卷按整份布置，沿用全卷题号，本版学生档案不另存或显示章节标题。“下载 PDF”下面的“布置给学生”把正在排的这份资料（Word、组卷篮或智能组卷）布置给选中的学生，智能组卷的方案默认选中它的学生。布置时不预设日期；分天只表示任务分组，可以分开完成，只记录实际提交日期。题目、答案和分天按当时的样子存进每位学生的作业，学生交上来后在学生档案的“作业”里上传批改，详见 `docs/homework-product-design.md` 的“布置作业”。
分天排版：智能组卷交给快速排版的题按天分组；已有调用默认仍使用分天模式，组卷篮显式使用章节模式。每组用分节样式的组标题，第二组起另起一页，标题下一行留“日期、用时、做对 __ / N 题”；每组题号从 1 开始；附答案时文末答案按组加小标题；分组时标题区只留姓名、班级。预览和单题设置里题目写成“第 2 天 第 1 题”。题目锚点 `q1…qN` 仍全局递增。
存储：表 `typeset_records`，`source_kind` 区分 Word 记录（word）和智能组卷的题目清单（library，`plan_json` 存方案，`student_id` 记为谁出的题，没有原始 Word）。原始 Word 存进分块素材表 `question_assets`，但不授予任何题库读取权限，`/api/assets` 不提供它，只能经本人记录的 `/api/typeset-records/:id/source` 读取。同一份 Word 只存一份，随最后一条用它的记录一起删除。上传用 JSON 里的 data URL：框架会把所有 multipart POST 当成 server action，并限制在 1MB 以内。

PDF 的答案和解析正文左对齐，长分式串可在运算符处换行，保留公式字号及完整内容，避免为了两端对齐将公式挤出页边界。

## 工具箱 · 智能组卷

组卷进度（学生、需求、方案题目与顺序、标题、每天主题、未提交的调整意见和排除题目）按登录用户自动保存在当前浏览器；退出工具箱或刷新后自动恢复，学生入口和指定历史记录分别恢复各自的草稿。自动保存不跨设备，清除浏览器数据会丢失；失败时页面明确提示。“保存方案”无需进入排版，复用快速排版历史记录，后续保存更新同一记录；通过“已保存方案”进入历史重新打开。手动保存后的新修改仍需再次保存才更新历史；重新生成成功后视为新方案，不覆盖上一份历史记录。正在生成的请求不在后台继续，退出前尚未返回的结果无法恢复。

老师用一句话说要出什么练习，可以选一位学生（学生档案页头部的“智能组卷”按钮会带上这位学生）。先读学生档案：老师备注、批改出的正确率最低的知识点、错误类型统计、最近 60 条答错或部分答错的批改、能力诊断和最近作业报告的薄弱点。错题只读已发布且无需人工复核的批改，保留作业名、题号、上传次数、学生原答、批改反馈、步骤分析，以及原卷局部红圈中的具体错因；未作答单列为待确认记录，不据此推断学生不会某个知识点。再对照题库目录理解需求，定出标题、天数、每天题数、内容范围（只能是题库里已有的分类）、题型、难度安排、侧重点和档案要点。档案要点只保留有明确批改依据、与本次练习相关的具体错因，须从同一条历史记录开头逐字引用作业名、题号、上传次数及错误原文；程序核对引用，改写、拼接或编造的依据不进入选题。

候选题是范围内的题，去掉这位学生错题本里的原题、以往智能组卷给他出过的题、布置给他的作业里的题库题和题干重复的题；超过 400 道时按编号均匀抽取。每道候选题附上从公式读出的特征（分数、带分数、小数、乘方、绝对值、括号前负号、多层括号、分配律形式、除法、含字母）和繁度（1–5，按运算个数、分数和括号算，仅辅助衡量计算量，不代表数学难度）。实际挑题时同时传入学生档案原文和已核对的错因依据。优先选能训练具体错误步骤的新题，选中的历史错因标签须与依据一致，程序在每题现有的理由里附上历史来源及错误原文，再说明新题的式子或条件如何训练这一步；只有同一知识点或相似符号不算已对应。题库缺少合适题或证据不足时标为“一般巩固”，不勉强关联。程序核对引用来源；题目与错因的数学对应仍由选题模型判断，老师可按每题理由审核。理由和档案依据中的公式沿用题库公式显示。选题同时收到老师原始要求和整理后的要求，最新调整意见优先；调整时保留上一版未被修改的要求。只有明确要求递进才逐日加深，未指定时不默认递进，单日题目顺序与各天之间的难度分别处理。

服务端只接受候选里的编号，去掉重复，每天截到题数；不足时按侧重点特征和繁度补选，理由写“系统补选”，针对学生时明确为“一般巩固”，不附未经核对的历史错因。补选完成后，若难度说明明确要求各天平均、持平或相近，程序检查各天题数、题库难度档位、繁度档位和繁度总量；差异超过一个题目或一个繁度单位时，在已选题中重新均衡分配，尽量使各天构成和计算负担接近。已均衡的方案保留原题序和主题；重新分配的天使用“均衡练习”主题，不再追加侧重点清单，题目的理由和侧重点随题保留。候选不足时不重复或凭空造题，尽量平均分配已有题。这是按现有标签和繁度做的近似检查，不能证明实际数学难度相同；不增加模型调用，仍为理解需求、挑题两次。

每天的主题作为组卷页和打印试卷的副标题，生成时要求用 6—12 字（最多 16 字）概括当天最主要的 1—2 个训练要点，例如“分配律与符号”“通分约分巩固”；不罗列全部侧重点、历史错因或解释句。完整错因和训练目的仍放在每题理由中。旧方案或本机草稿中“均衡练习 · …”自动拼接的长主题（超过 16 字），重新打开时统一简化为“均衡练习”，组卷页、排版预览和重新下载的 PDF 使用同一主题；简短主题、其他手动主题及主动留空保持原样。

每题下方默认只显示 ID、繁度和绿色侧重点标签；“一般巩固”“针对历史错因”的完整说明在鼠标悬停标签或键盘聚焦时显示，保留历史作业、题号、上传次数和公式。鼠标可移入浮层继续阅读，移开、焦点离开、Esc 或滚动方案时收起；浮层随可用空间向上或向下展开，不撑高题目行。缺少侧重点但有理由时，使用“一般巩固”“针对历史错因”或“选题说明”作为入口。

方案页按天列题：可以换一道（从范围内同侧重点、繁度最接近、这位学生没做过的题里换）、上移、下移、移除、加一道；手动换题、加题不重跑模型，因此针对学生时将新题标为“一般巩固”，不继承原题的历史错因依据。也可改天的主题和练习标题，或写一句意见让模型在原方案上调整，重新读取档案并核对错因，意见没提到的部分尽量保留。“排版”先校验下载权限，再把方案存进快速排版历史（同一份方案再次排版时更新原记录），然后在本页打开快速排版，每天单独起页。地址带 `?record=` 时打开这份方案接着改。接口：`POST /api/smart-paper`，规则和提示词在 `lib/smart-paper-contract.ts`。历史方案保持原样，新生成或调整后才补上具体错因对应关系；不新增数据库字段或方案属性。

题目内容匹配保留 LaTeX 分式、根式、指数及下标的范围。仅规范化空格、全半角、字体和定界符尺寸等排版差异；普通去重与印刷 ID 核对均不能用相似度容忍数学结构变化。单独识别的小问可以对应整题中的公共条件和本小问，但匹配不能从数学分组内部截取。修复匹配规则不会批量重写或合并历史题目 ID。

普通邀请码注册只创建会员，注册邮箱不用于决定权限。首次管理员按 README 的受控 D1 初始化流程建立；之后由已登录管理员在共享办公中授权。
