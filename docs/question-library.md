# 题库编号与查找

所有题库模块共用编号，已有题目按创建时间补号，新题由数据库原子分配。编号从 `0001` 开始，至少四位；超过 `9999` 后自然扩展为五位，不截断或复用。

题卡与讲义选题器显示 ID。输入完整 ID 命中题目时跨模块、分类和题型精确查找；未命中则仍按现有范围搜索正文、答案、年份和知识点。

内部 UUID 继续用于讲义与图片关联。`question_codes` 按 UUID 保存独立的永久编号，因为题目表含发布版本且可被物理删除，不能直接用行号稳定编号。编辑、移动、删除恢复、同 UUID 的发布版本均保留编号；导入为新 UUID 的副本分配新编号。编号由服务端控制，不接受客户端指定。永久删除也保留编号映射，避免旧编号指向其他题。

编号唯一性范围为当前数据库内的所有题库；独立部署各自分配，不承诺跨服务器相同。作业批改中的临时题目和学生错题记录不属于题库记录。

## 讲义书架

讲义只有一种，按存放位置分在三个书架上，编辑器和导出都一样：

- **课程体系**：按年级、学期、课次编排，课次号就是讲义在本学期里的先后。全员共用。
- **专题库**：按函数、几何、代数、数论、数学思想五个板块存放知识专题，不分年级。全员共用。以前没有归入课次的讲义暂放在“未分板块”，移走后这一列就不再显示。
- **学生讲义**：挂在学生档案下，只有这位学生的老师能看到、编辑和删除；删除学生时，这位学生的讲义一起删除。

书架由讲义的存放字段推出，不另设类型：有学生的是学生讲义，有学期的是课程体系，其余都在专题库（按板块，没有板块的是未分板块）。共享讲义只有管理员能删除。

讲义书架页不再重复页面标题。左侧是书架导航，顶部可以按讲义标题或模块名查找全部书架；右侧用满整个宽度：课程体系并排列出所选年级的暑假、秋季、寒假、春季，专题库并排列出五个板块，学生讲义列出这位学生的全部讲义。每条讲义显示课次号（课程体系）、标题、各模块名和题数；上移、下移、复制一份、移到…和删除收在“更多”里，鼠标经过或键盘聚焦时出现，触屏上一直显示。每一列末尾是“添加第N讲”“新建专题”或“为某某新建讲义”。“移到…”可以在课程体系（选年级和学期）、专题库（选板块）和自己的学生之间移动，移到学生名下后只有自己能看到。编辑页底栏的返回链接写明讲义所在位置，如“初二秋季”“几何专题”或学生姓名，并回到对应书架。

## 讲义内选题

打开一份讲义后，桌面端采用左侧题库、右侧讲义的双栏布局，两栏独立滚动。左侧题库最左边是与题库页相同的知识目录，点选模块或分类即按该分类及其子分类筛选；旁边的选题列表可切换模块和题型、按 ID 查找并批量选择；指定讲义知识模块与例题／练习／变式后加入，已在讲义中的题目不可重复加入。加入后保留筛选条件和目标位置，清空本批选择。编辑页不设顶栏：返回、保存状态和导出放在知识目录底部，讲义标题放在右侧讲义栏顶部，随讲义一起滚动；选题列表上方加入位置占一行，搜索、模块和题型在列表够宽时占一行、否则占两行，题目卡片配图限高，让一屏能浏览更多题目。选题列表与讲义栏宽度大致相当，讲义栏不再大片留白。

右侧各栏的“从题库选题”会定位左侧并切换加入位置；“替换”在左侧选一道题替换，保留原位置和用途，也可取消替换。题目卡片上直接显示红色“移出讲义”按钮，点一下即从讲义移除，题库原题不受影响；改为其他用途、编辑原题放在“更多”里。删除目标模块后，加入位置回退到第一个现存模块；无模块时需先添加知识模块。宽度不超过 1200px 时隐藏知识目录（仍可搜索分类名），返回、保存状态和导出移到题库顶部；不超过 900px 时上下排列，题库结果区仍独立滚动。讲义列表、知识点编辑、自动保存及导出规则不变。

## 讲义精排 PDF：配图位置与分页

配图按原题的排法放。Word 导入的题目，题干里的图在原文哪两段之间、印出来多大、怎么对齐，PDF 就怎么排；一行放不下时整行等比缩到版心宽，不再统一挪到题干右侧或末尾。解析里的图也留在原位置（教师版答案框和文末答案）。截图录入的题目按原截图中配图的位置（右侧或下方）和所占行宽比例排。其他题目沿用题干左、配图右等自动排列。

分页时，分节标题和例题／练习／变式标签总跟后面的第一道题在同一页，放不下时一起移到下一页。一道题（题干、配图、选项、考点、作答横线、课堂笔记区）放得进一页就整题不拆开，超过一页才在题内分页。教师版答案框跟在题目后面，答案长时可以接着排到下一页。文末答案中短的条目整条不拆，长解析可以跨页。页眉显示本页最先出现的分节，本页没有新分节时沿用上一页的。填空横线在行末放不下时最多缩短四成，不伸出版心。
